# Practice Pull Request Workflow

## Task Brief
Submit a pull request for the data transformation branch.

## Scenario
As a Data Scientist, you need to submit a pull request with your data transformation changes for review and integration.

## Deliverables
- Merged pull request

## Success Criteria
- Pull request adheres to team coding standards.
- Code review feedback addressed.
- Changes integrated into the main branch.
- Pull Requests: Pull request created with meaningful description.
- Pull Requests: Code reviewed by peer.
- Pull Requests: Pull request merged into main branch.
