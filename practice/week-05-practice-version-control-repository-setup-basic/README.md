# Practice Version Control: Repository Setup & Basic Commands

## Task Brief
Initialize a Git repository for the data analysis pipeline and commit initial files.

## Scenario
As a Data Scientist, you need to initialize a Git repository for your data analysis pipeline project to track changes and collaborate effectively.

## Deliverables
- Functional Git repository

## Success Criteria
- Repository initialized with a README file.
- Initial project files committed to the repository.
- Repository Setup: Initialized a Git repository for the project.
- Basic Commands: Committed initial project files to the repository.
