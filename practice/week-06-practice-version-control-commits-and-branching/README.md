# Practice Version Control: Commits and Branching

## Task Brief
Create a branch, commit changes, and practice branching strategies.

## Scenario
As a Data Scientist, you need to create a new branch for data transformation and commit your changes.

## Deliverables
- Functional Git repository with branch and commits

## Success Criteria
- Branch created successfully.
- Commits follow best practices.
- Changes are isolated to the new branch.
- Commits: Commit messages are clear and concise.
- Branching: Successfully create and switch between branches.
